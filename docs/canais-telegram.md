## Cuidados

- Entre só por link de site oficial ou pelo `t.me` acima. Convite de grupo desconhecido (`t.me/+...`, `chat.whatsapp.com/...`) é golpe comum.
- Grupo que pede dinheiro, cadastro ou "pix para liberar" não é de promoção.
- Se um canal virar chat de conversa, o filtro do app só aceita mensagem com link de loja que toque um dos seus Alvos.
