# Hoje 1. Fundação enxuta

Siga o CLAUDE.md, começando pela seção "Plano acelerado". Rode `git init -b main` com o kit e o .gitignore, e faça o commit "kit inicial". Crie o projeto Garimpo com Next.js 16.4 (App Router), TypeScript, Tailwind e shadcn, e uma pasta worker/ com tsx watch no mesmo repositório. Use PostgreSQL com Drizzle (DATABASE_URL no .env), só com as tabelas sources, raw_messages, offers, products, price_points, alvos, ai_usage e insights. O script pnpm dev sobe o Next (com -H 0.0.0.0, para o PC de 8 GB abrir pela rede) e o worker juntos, com concurrently. Não use pg-boss hoje. Se o create-next-app recusar a pasta com arquivos, crie o projeto numa pasta temporária e mova para a raiz sem apagar o kit.
Pronto quando: pnpm dev abre localhost:3000, o worker loga "worker ok" e as tabelas aparecem no DBeaver.
